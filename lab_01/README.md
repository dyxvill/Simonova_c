Цель работы:
Научиться работать с базовыми типами данных языка C, понимать связь 
переменных и памяти, использовать операции и выражения, выполнять ввод и 
вывод данных, а также понимать переполнение и точность вычислений.
Задание 1. Первая программа с переменными
Создайте программу, которая объявляет переменные int a, float b, char c. 
Присвойте им значения и выведите их на экран.
Пример вывода:  	a = 10
	b = 3.14
	c = A
Задание 2. Размеры типов
Напишите программу, которая выводит размеры типов char, int, float, double 
с использованием оператора sizeof.
Пример вывода: 	char: 1 	int: 4 	float: 4 	double: 8
Задание 3. Переменные и память
Создайте переменные int a, float b, char c и выведите их значения и адреса 
в памяти.
Пример вывода: 	a = 10, address = 0x7ff... 	b = 3.14, address = 
0x7ff... 	c = A, address = 0x7ff...
Задание 4. Остаток от деления
Считать два числа и вывести остаток от деления одного числа на другое с 
использованием оператора %.
Задание 5. Инкремент и декремент
Создайте переменную int a = 5. Выведите результат после операций a++, ++a, 
a--, --a.
Задание 6. Преобразование типов
Создайте переменные int a = 5 и int b = 2. Вычислите a / b. Затем измените 
программу так, чтобы результат деления был 2.5.
Задание 7. Потеря точности
Напишите программу с переменными float a = 0.1 и float b = 0.2. Выведите 
результат a + b с точностью 20 знаков после запятой.
Задание 8. Переполнение
Создайте переменную int x = 2147483647. Прибавьте к ней 1 и выведите 
результат. Объясните, почему получился такой результат.
Задание 9. Вычисление формул
Напишите программу, которая считывает число x и вычисляет значение 
выражений x^2 + 2x + 1 и (x + 1)^2 − (x − 1)^2.
Задание 10. Обмен переменных
Есть переменные int a = 5 и int b = 10. Поменяйте их значения местами с 
использованием третьей переменной.
Задание 11. Последняя цифра числа
Считать целое число и вывести его последнюю цифру.
Задание 12. Разложение числа
Считать трёхзначное число и вывести отдельно количество сотен, десятков и 
единиц.
Задание 13. Формат времени
Считать количество секунд с начала суток и вывести время в формате 
HH:MM:SS.
Задание 14. Исследование памяти
Создайте переменные int a, b, c. Выведите их адреса в памяти и вычислите 
разницу между адресами переменных. Объясните результат.
