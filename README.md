Цель работы: освоить работу с файлами, открытие и закрытие потоков, чтение и запись текстовых и бинарных данных, форматированный ввод-вывод, перемещение по файлу.


Использованные технологии: работа с файлами в виде функций и режимы открытия


Как запустить: 1) gcc task(номер).c -o task(номер) 2) ./task(номер) 

Ответы на вопросы:
1)Файл - область на диске для хранения данных.
2)FILE* - указатель на структуру, которая содержит информацию о файле (позиция чтения/записи, буфер и т.д.).
3)Режимы: "r" (чтение), "w" (запись, создаёт новый), "a" (дозапись), "rb"/"wb"/"ab" (бинарные аналоги), "r+" (чтение+запись).
4)Текстовый - хранит символы, переводит \n в пару CR+LF на Windows. Бинарный - хранит данные "как есть" (байт в байт).
5)putc - записывает один символ в файл. getc - читает один символ из файла.
6)fputs - записывает строку в файл. fgets - читает строку из файла (включая \n).
7)fprintf - форматированная запись в файл (как printf). fscanf - форматированное чтение из файла (как scanf).
8)fwrite - записывает блок данных (массив, структуру) в бинарный файл. fread - читает блок данных из бинарного файла.
9)fseek - перемещает указатель позиции в файле. ftell - возвращает текущую позицию указателя.
10)feof - проверяет, достигнут ли конец файла. ferror - проверяет, произошла ли ошибка при работе с файлом.
11)Важно закрывать файл, чтобы сохранить все данные из буфера на диск и освободить ресурсы системы (иначе возможна потеря данных).
