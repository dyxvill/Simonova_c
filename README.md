Цель работы: изучить работу с динамической памятью: функции malloc, calloc, realloc, free, создание и использование динамических массивов.

Использованные технологии: функции malloc, calloc, realloc, free, создание и использование динамических массивов.

Как запустить: 1) gcc task(номер).c -o task(номер)
2) ./task(номер) 
Ответы на вопросы:

1. Что делает malloc?
Выделяет блок памяти заданного размера в байтах, но не инициализирует его.

2. Чем отличается malloc от calloc?
malloc:
•	не инициализирует память 
•	принимает один аргумент 
calloc:
•	заполняет память нулями 
•	принимает два аргумента 


3. Что делает realloc?
Изменяет размер ранее выделенного блока памяти, сохраняя при этом существующие данные.

4. Что произойдет при утечке памяти?
Программа будет потреблять всё больше памяти, что может привести к замедлению работы, зависанию или аварийному завершению программы/системы.

5. Зачем нужен free?
Освобождает ранее выделенную динамическую память, чтобы её можно было использовать снова.

6. Что произойдет при двойном освобождении памяти?
Непредсказуемое поведение программы.

7. Как проверить, что malloc вернул NULL?
int *arr = malloc(100 * sizeof(int));
if (arr == NULL) {
    printf("Ошибка обработки памяти\n");
}
8. В чем отличие статического и динамического массива?
Статический: размер фиксирован, сам удаляется
Динамический: размер можно изменить во время выполнения, нужно удалять вручную через free
