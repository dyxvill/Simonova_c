Цель работы:
Изучить объявление и использование структур, вложенные структуры, указатели на структуры, массивы структур, передачу структур в функции, перечисления (enum) и объединения (union).
Использованные технологии: структуры, вложенные структуры, указатели на структуры, массивы структур, передачу структур в функции, перечисления (enum) и объединения (union).
Как запустить:
gcc task(номер).c -o task(номер)
./task(номер)
Ответы на вопросы: 
1. Как объявить структуру в языке C
Структура объявляется с помощью ключевого слова struct, после которого указывается имя структуры, а внутри фигурных скобок перечисляются переменные-поля с их типами.
2. Что такое вложенные структуры и зачем они нужны
Вложенные структуры — это когда одна структура содержит внутри себя другую структуру в качестве одного из полей. Это нужно для логической группировки данных. Так код становится понятнее и организованнее.
3. Как передать структуру в функцию
Есть два способа. Первый — передача по значению, когда в функцию копируется вся структура целиком. Второй — передача по указателю, когда в функцию передаётся адрес структуры. 
4. Можно ли создавать массивы структур
Да, можно. Массивы структур создаются точно так же, как массивы любых других типов. Например, можно создать массив на 100 студентов. Каждый элемент такого массива будет отдельной структурой со всеми её полями.
5. Как обратиться к элементу массива структур
Сначала указывается имя массива с индексом элемента в квадратных скобках, а затем через точку указывается имя поля. 
6. Можно ли использовать enum внутри структуры
Да, можно. Enum (перечисление) — это отдельный тип данных, поэтому его можно использовать как тип поля структуры. 
7. Можно ли сравнивать структуры оператором ==
Нет, нельзя. Оператор == не работает со структурами. Если попробовать написать структура1 == структура2, компилятор выдаст ошибку.
